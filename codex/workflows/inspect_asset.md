# Inspect selectively

Use `inspect <id> --blend <file>` for compact counts/components/bounds. Add
`--component <name>` for transforms, materials, hierarchy, collections, and state.
To operate on a semantic collection, select its components from the inspection
records and repeat `--component` for those identities.

Numerical and structural questions need no render. Use `preview` with the same
component and one or two useful `--view` values when silhouette/placement/appearance
needs judgment. Prefer the matching local reference crop. Read `docs/previews.md`
for framing and debug behavior; retain framing for comparable iterations.
