## Последовательность и критерии

1. Сохранить SHA исходников, настройки и установленные пакеты; скачать официальный
   Windows ZIP Blender 5.3.0 и проверить SHA256 по официальному checksum-файлу.
   Пользователь затем выбрал самостоятельную установку MSI: ссылка предоставлена,
   автоматическая установка и переключение отменены. Неподключённая portable-копия
   и скачанный ZIP удаляются только после проверки принадлежности файлов архиву.
   Совместимость с 5.3 подтверждать только после установки и фактического прогона.
2. Добавить в preflight владельцев каждого Action, а в GLB inspection — индексы
   целевых узлов и иерархию. Postflight отклоняет чужие цели, включая одноимённые
   кости другого рига. Существующие поля отчёта остаются; это внутренний контракт,
   новый export всегда получает свежий preflight. Проверка не обещает равенство
   всех численных кривых, физическую достоверность или новые анимации.
3. Проверить регрессию чистым Python и реальным Blender export, включая повреждение
   временного GLB и сохранность предыдущей выдачи. Затем штатные Python/Blender
   suites, башни и standalone ZIP. Blender запускается последовательно с отдельным
   профилем; старые результаты 5.2 не подтверждают 5.3/Vulkan.
4. Выпустить согласованную версию Core/add-on/Codex, обновить описание проверок.
   Проверить точные ZIP, установить через существующий installer/CLI; не править
   файлы установленного cache вручную. Проверить сохранение остальных дополнений
   и регистрацию GAT в новом процессе Blender. Переключать рабочий инструмент
   только после успешной проверки. Старую установку и профили сохранить.
5. Проверенные изменения опубликовать отдельным коммитом и push в текущую ветку;
   записать реальные версии, SHA пакетов, команды, отказы и непроверенные пункты.

## Границы и восстановление

Изменение ограничено export validation, адресными тестами, версиями, документацией
и установкой инструмента. Не менять Godot runtime, canonical .blend, игровые
материалы, баланс, thermal/route rules. Новые зависимости не нужны. Исходные
пакеты/настройки сохраняются до установки; при отказе восстановить только свои
изменённые файлы по SHA, без Git reset/clean. Не заменять пользовательские сцены
или startup.blend. Итоговые результаты дописать после фактических проверок.

## Проверенные результаты текущего этапа

### Дополнительная совместимость сохранённых fingerprints

Проверка шести старых canonical в Blender 5.3 выявила ложные предупреждения
о ручных изменениях. Причина подтверждена на 616 объектах: в Principled BSDF
добавлены `Transmission Dispersion Scale` (0) и `Transmission Dispersion Abbe Number`
(20), а fingerprint включает все inputs. Исключение только этих двух новых
значений в RAM восстановило все старые хеши; сами файлы остались прежними.

Реализовано: сохранён полный fingerprint для новых генераций,
а сравнение старого хеша разрешено только с проекцией этих двух inputs при точных
значениях по умолчанию и отсутствии связей. Остальные данные сравниваются полностью.
Все четыре читателя guard используют один helper: lifecycle, recolor, validation,
material inspection. Не менять сохранённые baseline-хеши и не применять
`replace_edited`. Адресные проверки отклоняют изменённую геометрию, трансформации,
старые параметры материала, новые значения dispersion и новые связи; legacy source gate и точные ZIP gates повторяются перед публикацией.

Пользователь самостоятельно установил официальный Blender 5.3.0. Неподключённая
portable-копия и её ZIP удалены после проверки всех 6628 файлов по архиву.
Исправление прошло 129 Python-тестов, 180 Blender-тестов и 2 rollback-сценария.
Standalone add-on ZIP прошёл 41 тест/1137 условий; оба ZIP прошли изолированный
CLI/UI round trip. Версии Core, Blender add-on и Codex manifest следующего пакета — 0.5.1.
Совместимость добавила 12 Python и 7 Blender tests: итого 141/187 и 2 rollback.
GAT установлен и включён в Blender 5.3 и Codex через штатные installers. Старый
профиль 5.2 сохранён: все 107 файлов остались прежними. Его копия перенесена
в отсутствовавший профиль 5.3; список 11 включённых дополнений сохранён.
Исходные пакеты/профиль имеют локальные backups. Установленные файлы сверены
с проверенными ZIP. Публикация проверяется отдельно по remote SHA; результаты
и хеши сохраняются в локальном QA без публикации пользовательских профилей.
