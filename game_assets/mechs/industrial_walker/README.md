# Industrial Walker — Mech Generator MVP

Рецепт поддерживает только стадию BLOCKOUT внутри существующего GameAssetTools.
Refinement и детализированные материалы в MVP не объявлены готовыми.
Выберите категорию `mechs`,
asset `industrial_walker`, затем **Build**. Размеры, углы и симметрия находятся
в стандартной Geometry-панели. Изменения применяются через **Rebuild**, с прежней
защитой ручных правок и заблокированных компонентов. `scout_mech` и башни сохранены.

Корпус — одна замкнутая сетка из трёх сечений. Бедро, голень, ступня и шарниры
раздельны; origins расположены на соответствующих осях. Вторая нога отражается
из первой на уровне вершин и winding, без отрицательного object scale.
Сложное оружие, динамика, материалы и control rig в этот MVP не входят.

Координаты: метры, +Z вверх, −Y вперёд; углы конфигурации — градусы.
`legs.hip_angle` отклоняет бедро назад от вертикали, `legs.knee_angle` задаёт
обратный сгиб относительно бедра. Высота таза рассчитывается по длинам звеньев;
подошва остаётся на Z=0. Стандарт `hinge_v1` задаёт палец 0,28м, номинальный
диаметр отверстия 0,284м, осевую ширину 0,32м. Крепления `Mount_OUT_Left/Right`
и `Mount_IN` имеют встречные оси и метаданные посадки. Внутренняя полость
подшипника условная: ради экономии полигонов сплошной кожух её не вырезает.

`RECIPE.mechanical_report(config)` не создаёт Blender ID и возвращает ошибки,
предупреждения, координаты суставов, размеры креплений, длины, зазоры, опору
и приблизительный COM. Ошибки отклоняются до изменения сцены. Проверки MVP
не являются полным поиском пересечений или расчётом прочности и динамики.
COM вычислен для одинаково плотных сплошных деталей без пустот и экипировки;
опора — оболочка вписанных прямоугольников подошв. Режим без зеркальной ноги
предназначен только для осмотра одного модуля и явно выдаёт предупреждение.

Конфигурация хранится в `config.json`. Общий CLI принимает `--config` при build/
rebuild; стандартные операции плагина сохраняют `.blend` и экспортируют static
GLB. JSON-presets и подробный механический отчёт использует общий интерфейс
GameAssetTools. Подтверждённые результаты Blender/Godot-проверок приводятся
в общем отчёте этапа; наличие рецепта само по себе не доказывает их прохождение.
